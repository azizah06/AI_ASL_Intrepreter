# ASL_Intrepreter
Tugas Besar Artificial Intelligent

## 🚀 Instalasi
**Clone repository ini**
```bash
git clone https://github.com/username/asl-cnn-project.git
cd asl-cnn-project
```


## 🧠 Cara Menjalankan Model
**Training model**
```bash
python model2.py
```
**Deploy webcam**
```bash
python webcam2.py
```

Pastikan folder dataset/ berisi dataset ASL yang sudah diproses.
📊 Hasil Evaluasi
Akurasi: 82%

Model: CNN dengan beberapa Conv2D, MaxPooling2D, dan Dense layer
Disimpan sebagai: asl_cnn_model.h5

📌 Sumber Dataset
Dataset diambil dari: https://www.kaggle.com/datasets/grassknoted/asl-alphabet
